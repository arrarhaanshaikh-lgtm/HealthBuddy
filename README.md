# 🏥 HealthBuddy

> **A Universal Multi-Demographic Health & Hygiene Web Application**

HealthBuddy is an interactive, accessible web application designed to promote better daily health and hygiene practices across all age groups in a household or school community. Created as part of the Community Engagement Project (CEP), HealthBuddy provides specialized, profile-adapted user interfaces tailored specifically for School-Going Kids, Homemakers, and Elderly Persons.

---

## ✨ Core Features by User Mode

### 🧒 1. Kids Mode (Gamified & Interactive)
- 20-Second Handwash Companion: Animated interactive countdown timer with step-by-step visual cues and celebratory rewards upon completion.
- Daily Hygiene Quests: Gamified checklists (brushing teeth, sanitizing supplies) earning XP points and digital badges.
- Germ Education Cards: Engaging interactive flip cards teaching basic germ transmission and sanitation concepts.

### 🏠 2. Homemaker Mode (Practical & Ergonomic)
- Kitchen Sanitation Tracker: Checklists and schedules for preventing cross-contamination, deep cleaning, and food safety.
- Ergonomic Break Guide: Timed 2-minute daily stretch routines with visual exercise cards to prevent joint and lumbar strain.
- Family Wellness Vault: Centralized manager for family vaccination schedules, nutritional planning, and health records.

### 👴 3. Elderly Mode (High-Accessibility & Safety)
- Accessible Design UI: High-contrast color palette, extra-large touch targets, and clear typography.
- Medication & Hydration Tracker: Single-tap visual buttons to log daily medication doses and track water intake.
- One-Touch SOS Emergency Alert: Prominent emergency button triggering immediate alert modals with location data and contact actions.
- Home Fall Prevention Guide: Simple visual checklists for checking lighting, non-slip mats, and floor safety hazards.

## 🛠️ Tech Stack

- Framework: React + TypeScript + Vite
- Styling: Tailwind CSS
- Icons & Animations: Lucide Icons, Framer Motion
- Deployment: Vercel / Netlify

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have Node.js (v18 or higher) and Git installed on your computer.

### Installation & Run Steps

1. Clone the repository:
   git clone https://github.com/arrarhaanshaikh-lgtm/HealthBuddy.git

2. Navigate into the project directory:
   cd HealthBuddy

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev

5. Open in Browser:
   Open http://localhost:5173 in your browser to view and test the application.

---

## 🌐 Deployment

This project is deployed using Vercel:

1. Sign in to Vercel (https://vercel.com) using your GitHub account.
2. Select Add New... -> Project.
3. Import the HealthBuddy repository.
4. Keep the default Vite build settings (npm run build, output directory dist) and click Deploy.
